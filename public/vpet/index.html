🌸 Pollinations — GitHub 登录与配置

通过 GitHub 授权登录 Pollinations，获取免费 API 额度，按步骤完成操作

1
打开 GitHub 注册入口
打开 GitHub 官网，点击右上角的 注册 按钮，开始创建你的 GitHub 账号。
2
填写注册信息
在注册页面依次输入你的 邮箱、密码、用户名 和 所在国家，然后点击 创建账户 按钮。
3
输入邮箱验证码
GitHub 会向你的注册邮箱发送验证码。在页面中输入收到的验证码，然后点击 继续 按钮完成验证。
4
登录你的 GitHub 账号
注册完成后，在登录页面再次输入你的 邮箱 和 密码，点击 登录 按钮进入 GitHub。
5
GitHub 登录成功
登录成功后，你会看到 GitHub 首页。此时账号已成功创建，可以继续下一步操作了。
6
打开 VPet 网页点击授权
打开 hzliflow.ken520.top/vpet 网页，点击页面上的 授权 按钮，开始关联 GitHub 账号。
7
点击连接 GitHub
在授权页面中，点击 连接 GitHub 按钮，系统将跳转至 GitHub 授权页面。
8
授权 GitHub 账户
在跳转的 GitHub 授权页面，点击 授权 GitHub 账户 按钮，完成账号关联。
9
配置数据并创建
完成授权后，进入配置数据页面。将下面两个输入框清空内容，然后点击 创建 按钮完成配置创建。
10
打开 Quests 任务页面
打开 enter.pollinations.ai 页面，在左侧导航栏选择 Quests 并点击进入任务页面。
11
领取任务奖励
在 Quests 页面领取 2 个任务奖励，获得初始额度。这些额度用于后续的 AI 对话和绘图功能。
12
进入对话卡片
返回 hzliflow.ken520.top/vpet 页面，点击 对话卡片，进入 AI 对话界面。
13
发送对话测试
在对话框中简单发送一条消息，等待 AI 正常回复。确保对话功能正常工作后再继续下一步。
14
进入绘画卡片
点击 绘画卡片 进入绘图功能页面，体验 AI 绘图能力。
15
生成测试图片
在绘图输入框中随意输入一段描述，等待图片生成完毕。确认绘图功能正常可用。
16
测试音频模型
查看音频部分的模型是否可用。如果可用，自行生成一段音频进行测试，确认音频功能正常。
17
领取剩余奖励
回到 enter.pollinations.ai/quests 页面，领取剩余的 2 个任务奖励。你将获得 1 花粉，可以使用很久，并且能少用 0.2 的额度。
18
复制密钥按钮
回到 hzliflow.ken520.top/vpet 页面，点击上方的 复制密钥 按钮，获取你的 API Key。
19
粘贴 Key 并保存
将复制的 Key 粘贴到 mod 设置中的 Key 配置 输入框中，然后点击 保存 按钮完成配置。
20
启用智能多模型对话
最后，在游戏设置中的 聊天设置 中，选中 自定义聊天接口 中的 智能多模型对话，即可开始使用全部功能！

💧 AQUA公益AI — API Key 获取教程

AQUA公益AI 是一个免费公益 AI 平台，注册后即可获取 API Key。注意：多人共用同一 Key 可能导致 IP 被封，请自行注册。

1
打开 AQUA公益AI 注册页面
打开 acu.ltzy.top 网站，点击首页的 免费注册 按钮或右上角的注册按钮开始注册。
2
填写注册信息
在注册页面输入你的 用户名、邮箱、邮箱验证码 和 密码，然后点击 登录 按钮完成注册。
3
进入 API 密钥管理页面
注册并登录后，在页面左侧导航栏点击 API密钥，然后点击右上角的 创建密钥 按钮。
4
配置密钥名称
在弹出的配置窗口中，为你的 API Key 随便填一个名字（如"VPet"），方便以后识别。
5
复制密钥
创建完成后，点击密钥旁边的 复制 按钮将 API Key 复制到剪贴板。
6
粘贴到 Mod 设置页
回到 VPet 游戏的 Mod 设置页面，将复制的 API Key 粘贴到 AQUA 公益AI 的输入框中，点击保存即可使用。
