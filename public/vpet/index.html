API Key 注册与配置教程

按照以下步骤操作，即可免费获取 API Key 并开始与桌宠对话

1
找到 Key 注册入口
打开 mod 设置页面，在基础配置中可以看到 API Key 配置区域。点击相关按钮即可跳转到 Key 注册页面。

你也可以直接点击下方链接手动跳转：
前往 Pollinations 注册页面 →
2
登录注册页面
进入注册页面后，点击 登录 按钮。推荐使用 GitHub 账号登录，方便快捷。
3
登录成功
登录成功后，你会看到如下页面。确认你的账号信息已正确显示，然后准备创建 API Key。
4
进入 Key 密匙管理页面
在页面上找到 Key 密匙 按钮入口，点击进入 Key 管理页面。
5
创建新的 Key
在 Key 管理页面中，点击 创建新的 Key 按钮，系统会为你生成一个唯一的 API Key。
6
配置 Key 参数
点击创建按钮后，会进入 Key 配置页面（在网站上，非 mod 设置）。在这里可以设置：
Key Name（Key名称）、Key最大预算（默认即可）、Key失效时间、Key可用功能（选择需要的模型）。

配置完成后点击 确认 按钮。
7
复制你的 API Key
配置完成点击确认后，页面会显示你的 API Key 密匙。请立即复制并妥善保存，这个 Key 是你使用 AI 对话功能的凭证。

注意 Key 只会显示一次，请务必复制保存。如果丢失，需要重新创建。
8
粘贴 Key 并保存
将 Key 粘贴到输入框后，点击 保存 按钮。保存成功后，你就可以开始和桌宠对话了！
9
领取所有余额
配置完 Key 后，回到 Pollinations 网站的 Quests 标签页面，领取所有可用的余额奖励。这些余额用于 AI 对话，每小时刷新。

提示 余额用完后可以等待刷新，或通过完成任务获取更多额度。
